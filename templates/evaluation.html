4. Probability Calibration (Reliability Diagram & Brier Score)

Assesses whether predicted output probabilities reflect true empirical event frequencies (e.g., when model predicts 70% risk, do 70% of those crops actually underperform?).

Brier Calibration Score: {{ eval_data.classification.calibration.brier_score }}
Expected Calibration Error (ECE): {{ eval_data.classification.calibration.ece }}
Brier score calculates mean squared error of predicted probabilities against ground truth outcomes. Values below 0.10 indicate high calibration reliability.

Uncalibrated tree ensembles and sigmoid activations often output overconfident tail probabilities. Using reliability diagrams and isotonic/Platt scaling ensures risk scores can be trusted by farmers and agronomists for decision making.
